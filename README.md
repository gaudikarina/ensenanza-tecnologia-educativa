# Tecnología educativa y robótica · Educación media
*Educational technology and robotics · Secondary education*

Clases, actividades e instrumentos de evaluación de mi autoría para la asignatura **Innovación y Tecnología** (1.º a 5.º año de educación media), con enfoque de aprendizaje por proyectos. Los materiales son editables (`.pptx`, `.docx`).
